# 📝 TaskFlow

**TaskFlow** es una aplicación web de gestión de tareas construida con **React** y **Tailwind CSS**. Permite a los usuarios añadir, completar y eliminar tareas de forma rápida y responsiva. El estado de las tareas se guarda automáticamente en el navegador.

## 🚀 Tecnologías usadas

- React.js
- Tailwind CSS
- JavaScript ES6+
- LocalStorage

## 🎯 Funcionalidades

- ✅ Agregar tareas
- ✅ Eliminar tareas
- ✅ Marcar tareas como completadas
- ✅ Guardado automático en el navegador
- ✅ Responsive design para dispositivos móviles

## 📦 Instalación

```bash
git clone https://github.com/Alexander2k23/taskflow.git
